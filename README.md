# 기어 설계실 (Gear Studio)

기어·동작 기구·규격 부품을 설계하고, 3D로 움직여 확인한 뒤 3D 프린팅용 STL로 내보내는 웹앱입니다. 설치 없이 브라우저에서 `dist/index.html` 하나로 돌아갑니다.

## 지금 할 수 있는 것
- **기어박스 자동 설계**: 공간 모양·기능(감속·증속·직각·반전·유성)·동력원에 맞춰 기어열을 찾고, 모터 마운트·축·베어링·하우징까지 만듭니다.
- **기어 직접 설계**: 평기어·헬리컬·헤링본·베벨·유성·랙·웜·사이클로이드.
- **자유 조립**: 축과 단을 이어 3D 기어열을 짭니다.
- **캠 설계**: 변위 선도로 캠과 종동절을 만듭니다.
- **동작 기구**: 크랭크·슬라이더, 스카치 요크, 4절 링크, 얀센 링크, 제네바, 래칫, 리드스크루, 차동 기어. 모터 선택, 감속 기어, 마운트, 움직이는 동안 겹침 검사를 포함합니다.
- **동작으로 찾기**: 운동(연속 회전·직선·왕복·요동·간헐·진동)과 기능(들어 올리기·잡기·이송…)으로 기구를 고릅니다.
- **규격 부품**: 볼트·너트·와셔·베어링·리니어 부싱·풀리·스프로킷·커플링·유니버설 조인트·스프링·2020 프로파일·모터 모형 등을 치수로 골라 STL로 받습니다.
- **내보내기**: 부품별 STL, 출력판, 조립·분해 조립도, OpenSCAD, 부품표·조립 순서, 배선·아두이노 코드, 구입 부품 출력 모형.

## 개발
```
npm install      # 시험용 three.js
npm run build    # src/ → dist/index.html
npm test         # 빌드 + 기하 시험 (모든 기구·동력원·규격 부품)
```
- `src/`는 이어 붙이는 순서가 `build.json`에 적혀 있습니다. 모든 조각은 같은 전역 범위에서 돌아갑니다.
- `src/core`·`src/mechanisms`·`src/catalog`는 화면 없이 Node에서도 돌아가는 기하·설계 코드(`<script id="core">`)이고, `src/ui`는 화면 코드입니다.
- 앞으로의 구조는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)에 있습니다.
